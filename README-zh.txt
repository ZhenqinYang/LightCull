轻选 LightCull v0.2.7（测试版）

Windows 10/11 可运行的 PowerShell + WPF 选片工具。
解压到普通文件夹，双击 Start_LightCull.bat 启动。

右上角可以在“简体中文 / English”之间实时切换；语言选择会保存在电脑本地。
升级时务必同时复制 LightCull.I18n.ps1，新文件缺失时软件无法启动。

基本用法：
1. 打开照片所在的文件夹（当前目录，不扫描子目录）。
2. 选择按时间连拍分组，设定时间间隔，点击“应用分组”。
3. 使用左右方向键切换照片；X 标废片、K 保留，Space 放大。
4. 删除之前务必备份，并且先用复制的 5–10 对 JPG/RAW 验证。
5. 确认后将 JPG 和同名 RAW 一并移到 Windows 回收站。

数据安全：
- JPG/RAW 删除不是原子事务；发生失败后请检查原文件夹和回收站。
- 外接机械硬盘遇到 I/O 错误时不要继续删除，先排查 USB 连接及备份。
- 不会删除 XMP 边车文件，不会递归处理子文件夹。
- 本程序并非 EXE，第一次启动会用系统 Add-Type 编译随附 C#。
